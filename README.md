# DarkBoard

It's certainly not a whiteboard.

No-install whiteboard — open `index.html` in a browser, nothing to install.

Dark mode by default, with a Light board toggle.

Wacom support via the browser's Pointer Events: pressure-sensitive pen strokes, tilt readout, and automatic erasing when you flip the pen to its eraser end. Palm rejection ignores touch input while drawing.

Also included: highlighter, line / rectangle / ellipse shapes, text tool, 10 ink colours plus a custom picker, brush sizes, dot grid, pan and zoom on an infinite canvas, undo/redo, two-tap Clear, and PNG export.
